# Gotcha—Template for Google Chat Bot

This open-source project provides a foundational template for building Google Chat Bots with a serverless backend powered by Google Apps Script.

## Features

Quick Start: Includes basic structure for receiving messages and card clicks, allowing you to rapidly develop your bot's functionality.

Customizable: Simple structure makes it easy to modify and extend for your specific needs.
